# Крестики-нолики — Java для программистов. Часть 2

Консольная игра для двух человек на поле 3×3. Первый игрок ставит X,
второй — O. После каждого хода проверяются восемь выигрышных линий и ничья.
Дополнительно реализованы проверка ввода и случайный компьютерный соперник.

## Компиляция и запуск

Нужен JDK 17 или новее (команды `java` и `javac` доступны в PATH).
Зависимости, Maven и Gradle не нужны. Выполняйте команды из корня проекта.

PowerShell (Windows):

```powershell
New-Item -ItemType Directory -Force out | Out-Null
javac -encoding UTF-8 --release 17 -d out (Get-ChildItem src/*.java).FullName
java -cp out Main
```

Linux/macOS:

```sh
mkdir -p out
javac -encoding UTF-8 --release 17 -d out src/*.java
java -cp out Main
```

Для игры с компьютером: `java -cp out Main --ai`.
В IntelliJ IDEA откройте папку, назначьте JDK 17+, отметьте `src` как Sources Root
и запустите `Main.main()`. Консоль должна использовать UTF-8.

## Управление

Введите номер строки и столбца через пробел: `1 2` — верхняя средняя клетка.
Номера строк и столбцов от 1 до 3. Ошибочный ввод, выход за поле и занятая
клетка приводят к повторному запросу тому же игроку. `q` или конец входного
потока завершают игру. После победы или ничьей программа завершается;
для новой партии запустите её повторно.

## Проектные решения

- `Player` — абстрактный базовый класс с полями `name`, `mark` и методом
  `makeMove(Board)`. Аргумент передаёт поле для текущего хода; результат
  `false` означает отмену или завершение ввода.
- `HumanPlayer` и `AIPlayer` наследуют `Player` и переопределяют `makeMove`.
  AI случайно выбирает свободную клетку, стратегию победы не рассчитывает.
- `Board` содержит закрытый двумерный массив `grid`, отображает поле,
  размещает метки и определяет заполнение и победу.
- `Game` использует композицию: содержит `Board`, двух `Player` и ссылку
  `currentPlayer`. Управляет очередью ходов и объявляет результат.
- Один общий `Scanner` передаётся обоим людям. Поток вывода передаётся
  отдельно, чтобы сценарии можно было проверять без ручного ввода.
- Внутри поля индексы от 0 до 2; пользователь вводит координаты от 1 до 3.

## Самопроверка

После компиляции исходников скомпилируйте и запустите проверки:

```text
javac -encoding UTF-8 --release 17 -cp out -d out tests/GameTests.java
java -cp out GameTests
```

Проверяются все выигрышные линии для X/O, запрет неверных ходов,
ничья, победы обоих игроков, повтор ввода, выход и допустимые ходы AI.
